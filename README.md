# ⏰ Relógio Digital Simples  

Um relógio digital desenvolvido com **HTML, CSS e JavaScript**, exibindo a hora em tempo real de forma dinâmica e estilizada.  

🔗 **Acesse o projeto aqui:** [CodePen - Relógio Digital Simples](https://codepen.io/Amanda-Santos-the-builder/pen/VYZEJGB)  

---

## 📌 **Tecnologias Utilizadas**  
- **HTML5** → Estrutura do relógio  
- **CSS3** → Estilização da interface  
- **JavaScript** → Atualização dinâmica da hora  

---

## 🚀 **Como Funciona**  
1. O relógio exibe a **hora, minutos e segundos** em tempo real.  
2. A interface é simples e elegante, com atualização automática.  
3. Feito para rodar diretamente no navegador, sem necessidade de instalação.  

---

## 🎯 **Como Executar**  
1. Acesse o projeto no **[CodePen](https://codepen.io/Amanda-Santos-the-builder/pen/VYZEJGB)**.  
2. O relógio será exibido e atualizado automaticamente.
